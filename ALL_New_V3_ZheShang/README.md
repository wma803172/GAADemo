# Intel 18A · 硅基之旅

> MECH6045 Nanotechnology and Fundamental · 课程项目
> 一个滚动驱动的、可交互的 3D 讲解站：从 1960 年的平面晶体管，一路讲到 2026 年 Intel 18A 的 RibbonFET 与 PowerVia 背面供电。

这个目录以 V3 的滚动展览为基础。仓库根目录下的 `docs/` 保留了 V1《芯片的另一面》。

---

## 怎么打开

双击 **`start.cmd`**，在电脑浏览器中打开 [本地展览](http://localhost:8124/V4.html)。网页入口文件名为 `V4.html`。

需要 Node.js（任意 18+ 版本）。之所以不能直接双击 `index.html`，是因为全站是原生 ES Module，浏览器对 `file://` 的模块加载有限制。

手动启动也一样：

    node tools/serve.mjs . 8124

## 全片结构（15 章）

叙事主线是**七十年六次形状变化**，最后落到 18A 的两个关键手段：RibbonFET 与 PowerVia。

| # | 章节 | 进度区间 | 讲什么 |
|---|---|---|---|
| 01 | 序章 | 0.000–0.050 | 两条线索：栅极怎样控制沟道，电源怎样抵达器件 |
| 02 | 平面时代 | 0.050–0.130 | 以平面工艺为历史背景，用平面 MOS 晶体管说明从一面控制沟道 |
| 03 | 短沟道效应 | 0.130–0.205 | 栅长缩短 → DIBL / 亚阈值摆幅退化 |
| 04 | 2011 FinFET | 0.205–0.290 | 22nm Tri-Gate，三面包裹 |
| 05 | 2014 多鳍 | 0.290–0.375 | 多条鳍并排，让一个栅极控制并联沟道 |
| 06 | 2022 3nm | 0.375–0.460 | 栅下仍是竖鳍，栅外两端的源漏外延用带斜面的形状示意 |
| 07 | 2026 RibbonFET | 0.460–0.545 | 四条硅带各自被共用栅极环绕，沿沟道观察源漏之间的导电路径 |
| 08 | 正面互连 | 0.545–0.620 | 信号与电源挤在同一面，IR drop |
| 09 | 分家 | 0.620–0.695 | 比较两种布线方案，PowerVia 的主要电源网络放在背面 |
| 10 | PowerVia 总览 | 0.695–0.757 | 看器件两侧的多层网络，分清信号、供电和回流 |
| 11 | PowerVia 局部 | 0.757–0.800 | 跟随现有的通孔到器件侧边的本地触点，辨认正面栅极信号 |
| 12 | 退回全景 | 0.800–0.818 | 一个单元是这样，一整颗呢 |
| 13 | 一路拉远 | 0.818–0.890 | 晶体管 → 芯粒 → 封装 → 主板 → 整机 |
| 14 | 产品 | 0.890–0.950 | Panther Lake 计算芯粒与 Xeon 6+ 服务器处理器 |
| 15 | 收尾 | 0.950–1.000 | intel 字标 |

每章的权重写在 `src/content.js` 里，权重之和决定它在整条滚动轴上的占比。

## 技术栈

- **Three.js r170**（已内置在 `vendor/`，离线可用，不依赖 CDN）
- 原生 ES Module，无打包、无构建步骤
- HDR 环境光、实体接触阴影、ACESFilmic 色调映射与金属高光。字体与北斗七星背景在本地加载。
- 所有几何体都是程序化生成的（`RoundedBoxGeometry` / `ExtrudeGeometry` / 自写菱形棱柱），**没有一张 3D 模型文件**
- 滚动进度 `p ∈ [0,1]` 同步控制镜头、模型变形、文案和标注。镜头停在导通状态时，沟道中的亮点仍随时间移动。

## 数据来源

页面里出现的每一个数字都记在 `docs/research.md` 里，并标了 `[CONFIRMED] / [LIKELY] / [UNCERTAIN]`。

- **+18% 性能（同功耗）/ −38% 功耗（同性能）** 是 Intel 公布的 18A 数字，测试条件为 **0.75 V iso-power**；在 1.1 V 下约为 25% / 36%。
- **+30% 密度** 指同代混合库相对 Intel 3。
- 没有官方来源的量（例如 18A 的 ribbon 宽度、良率、nano-TSV 直径）**一律不写具体数值**。
