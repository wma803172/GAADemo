# Intel 18A · 硅基之旅

用一条向下滚动的轴，把晶体管从 1960 年的平面结构一路讲到 2026 年 Intel 18A 的 RibbonFET + PowerVia。

纯静态、无需构建、离线可跑。所有几何都是 Three.js 程序化生成的，仓库里没有任何 3D 模型文件。

## 怎么跑

两个目录各自独立，主版本：

    cd ALL_New_V3_ZheShang
    node tools/serve.mjs . 8123
    # 浏览器打开 http://127.0.0.1:8123

尝试版换个端口就能并排对比：

    cd ALL_New_Project_V2
    node tools/serve.mjs . 8124

也可以直接用任意静态服务器（python -m http.server、npx serve），因为**没有构建步骤**。

## 技术底子（两版共用）

| 项 | 做法 |
|---|---|
| **驱动** | 全站由**一个标量 `p ∈ [0,1]`** 驱动：相机、模型、文案、进度条、比例尺、3D 标签全是 `p` 的纯函数。没有定时器、没有事件，所以不会不同步 |
| **几何** | 全部程序化生成：RoundedBoxGeometry、ExtrudeGeometry（菱形剖面、字标）、自定义菱形棱柱 |
| **着色器** | 三个自定义：菲涅尔轮廓、energyFlow 流光、粒子点 |
| **光照** | PMREM 环境贴图（程序化 canvas 绘制）+ ACESFilmic 色调映射 + UnrealBloom；**不用阴影** |
| **离线** | Three.js r170 放在 `vendor/`，不依赖 CDN |
| **验证** | `tools/shoot.mjs` 通过 CDP 打开 Chrome，在任意 `?t=` 处截图逐帧核对 |
| **性能** | 实测 120 FPS（Intel Arc B390 / D3D11） |

## 数据来源

页面里的每一个数字都记在各版本的 `docs/research.md` 里，并标了 `[CONFIRMED] / [LIKELY] / [UNCERTAIN]` 与来源链接。

几条口径：

- **+18% 性能（同功耗）/ −38% 功耗（同性能）** 是 Intel 公布的 18A 数字，测试条件为 **0.75 V iso-power**；在 1.1 V 下约为 25% / 36%。
- **+30% 密度** 指同代混合库相对 Intel 3。
- **nano-TSV、ribbon 宽度、良率** 这类没有公开数字的项，**一律不写具体 nm 值**。

## 早先的一版：`docs/`

`docs/` 是这个仓库原有的那一版实现，视觉与交互风格另成一套，与上面两个版本互相独立、互不依赖。

沿着一个晶体管向下滚动，观察 RibbonFET 的四条硅纳米带怎样共用一个环绕栅，再跟着晶圆翻面，沿 PowerVia 的背面电网、通孔和本地接点追到器件。

下载并解压仓库后，双击 [docs/index.html](docs/index.html) 即可离线观看。要直接看背面电网，点网页顶部的「背面供电」，再向下滑动查看侧接通孔的特写。

结构采用示意比例。金色和蓝色分别表示供电和回流支路，青色表示正面栅极信号。
