# 设计与架构说明

## 一句话

整个站只有一条数据通路：**滚动位置 → 一个标量 `p` → 整个世界**。
除此之外没有计时器、没有事件链、没有状态机。

```
scrollY ─▶ p ∈ [0,1] ─┬─▶ 相机位置 / 朝向 / 视野
                      ├─▶ 每个模型的可见性、透明度、缩放、变形
                      ├─▶ 3D 锚点标签的屏幕位置
                      ├─▶ 右侧时间环的滚动
                      ├─▶ 左下角比例尺
                      └─▶ 左侧文案的显示 / 隐藏
```

因为所有东西都从同一个 `p` 算出来，**不可能出现「时间轴和画面对不上」**——这正是旧版本最难受的 bug。

## 章节表

`src/content.js` 里 13 个章节，每个带一个 `weight`，归一化成 `[start, end]` 区间。
想调节奏？改权重就行，所有联动（相机、标签、时间环）自动跟着走。

```js
{ id: 'gaa', weight: 0.085, rail: { year: '2026' }, title: '四条带子，<br><em>四面全包</em>。', ... }
```

## 相机

每个章节一个固定机位 `SHOTS[i] = { pos, tgt, fov }`。
章节内前 74% 停在原地（只做 3.5% 的极慢推进），后 26% 平滑过渡到下一章机位。

这样「停住讲」和「转场」是同一套代码，永远不会出现突然跳切。

## 模型

全部程序化生成，没有任何 `.glb` / `.obj`：

| 模块 | 内容 | 关键手法 |
|---|---|---|
| `models/planar.js` | 1960 平面晶体管 | 圆角盒子 + 半透明栅极 + 径向渐变热区 |
| `models/finfet.js` | 参数化 FinFET（1/2/4 鳍、3nm 菱形外延） | 同一份代码用 `fins` / `diamond` 两个开关切朝代 |
| `models/gaa.js` | RibbonFET | 用带 4 个洞的 `ExtrudeGeometry` 做出「四面全包」的栅极 |
| `models/stack.js` | 互连 / PowerVia | 每层只是一个 `Group`，`apply({split, drill, land})` 决定它在哪 |
| `models/macro.js` | 芯粒/封装/主板/笔记本 | 程序化贴图 + 圆角板 |

### 让「接触面积」看得见

这是全片的核心表达，用了三层叠加：

1. **栅极是半透明的玻璃**（`gateGlass`，opacity 0.15–0.3），能看见里面的硅带；
2. **硅带外面套一层会发光的「栅介质」**，只在被栅极包住的那一段亮，形成一圈光环；
3. **电子粒子**沿硅带流动（`Points` + 自定义 soft-dot shader），只出现在接触面上。

所以 FinFET 是三面包裹（上 + 左右），GAA 是四面（上 + 下 + 左右），观众一眼能数出来。

## 材质

`scene/materials.js` 提供 8 种：`silicon` `channel` `oxide` `metal` `emissive` `gateGlass` `rim` `energyFlow`。

- `rim` 是一圈 fresnel 外壳，负责 Intel 渲染里那种「金属被灯打亮」的棱线；
- `energyFlow` 是沿轴向流动的能量带，用世界坐标做相位，所以物体怎么动光带都不会跳。

环境光不是 HDR 文件，而是运行时用 canvas 画的一张等距柱状图再 PMREM 预滤——
里面刻意放了三条冷白灯带和一条暖色反射带，金属的高光就来自这里。

## 性能

- 光栅化 + 后期（ACES + UnrealBloom），没有阴影贴图（PPT 要求「去掉所有影子」）；
- 实测 1600×1000 / Intel Arc 核显：**120 FPS**（跑满刷新率）；
- 窄屏自动把相机后撤，保证主体不被裁掉；
- 右上角提供 高 / 中 / 低 三档：低档关掉 bloom、像素比降到 1.0。

## 自检工具

`tools/shoot.mjs` 用 CDP 直接驱动 Chrome：

```bash
node tools/shoot.mjs --url http://127.0.0.1:8123 --out shots/x.png --t 0.52,0.60
```

`t` 可以是任意进度，所以每次改完都能在同一批帧上做前后对比，而不是靠肉眼滚动。
所有验收截图都在 `shots/`。

## 可访问性 / 细节

- `prefers-reduced-motion` 时不跑文字位移；
- 文字用真实 `<h1>/<h2>/<p>`，有层级；
- 时间环、比例尺是 `aria-hidden` 的纯装饰；
- 键盘 `↑↓ PageUp PageDown Home End` 全部可用，答辩现场可以不用滚轮。
