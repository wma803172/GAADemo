## 多出来的三章

| # | 章节 | 标题 | 画面在做什么 |
|---|---|---|---|
| 01 | `open` | 先看结果：一颗 18A 的晶体管 | GAA 侧视，四条硅带悬空，左右两端 nano-TSV 亮起 |
| 02 | `make` | 先长一摞夹心，再把夹心抽掉 | **八步制造动画**，右下角同步显示「04 / 08 · 源漏外延」 |
| 03 | `why` | 这么麻烦，是为了少掉的那些电压 | 平面管（一面栅控）与 GAA（四面栅控）左右并排对比 |

### ① 八步制造（`src/models/fab.js`）

由**一个标量 `step`** 驱动，没有定时器：

    超晶格外延 → 刻成鳍 → 假栅落下 → 源漏外延
    → 去掉假栅 → 沟道释放 → 金属栅包覆 → 通电

刻蚀和抽层一律用 `scale → 0.001` 模拟，不做布尔运算——视角固定、层是独立网格，视觉上和真刻蚀没有差别，开销几乎为零。

调整入口：`tools/fab-preview.html?step=0.6`，可以单独看任意一步。

### ② 步骤指示条（`ui/ui.js` 里的 `StepNote`）

只在制造那一章出现，八步切换点与 `fab.js` 的阈值完全对齐，字幕和画面永远是同一件事。手机端自动移到右上角。

### ③ 左右对比

「为什么值得」不再复用第一章的画面，而是把平面管和 GAA 各缩到 0.52 并拉开，一眼看出「栅极从一面盖变成四面裹」。
