# 设计与架构说明

## 一句话

滚动位置决定进度 `p`，用来同步章节、结构变形、镜头和标注。导通路径中的亮点使用动画时间，停住滚轮也能继续观察。

```
scrollY ─▶ p ∈ [0,1] ─┬─▶ 相机位置 / 朝向 / 视野
                      ├─▶ 每个模型的可见性、透明度、缩放、变形
                      ├─▶ 3D 锚点标签的屏幕位置
                      ├─▶ 右侧时间环的滚动
                      ├─▶ 左下角比例尺
                      └─▶ 左侧文案的显示 / 隐藏
```

## 章节表

`src/content.js` 里有 15 个章节。`weight` 决定每章在 `[0, 1]` 上所占的区间。
调整章节长度时，需要同步检查 `chapters/stage.js` 里的镜头和对应模型的变形区间。

```js
{ id: 'gaa', weight: 0.085, rail: { year: '2026' }, title: '四条带子，<br><em>四面全包</em>。', ... }
```

## 相机

`chapters/stage.js` 的 `SHOTS` 记录进度、相机位置和观察目标。相邻机位之间平滑插值，使不同年代的器件保持一致的源漏朝向。PowerVia 的远景、推进、停留和拉回使用同一个空间坐标系。

## 模型

全部程序化生成，没有任何 `.glb` / `.obj`：

| 模块 | 内容 | 关键手法 |
|---|---|---|
| `chapters/device-transition.js` | 平面、单鳍、多鳍、GAA | 保持源漏参照位置，随进度改变中间沟道和栅极的几何形状 |
| `models/gaa.js` | 局部 RibbonFET | 四层水平硅带，位于中央的栅极环绕各层沟道 |
| `models/stack.js`、`chapters/power-detail.js` | 互连 / PowerVia | 比较正面供电与背面供电，展开分层布线，从总览追到器件旁的本地触点 |
| `models/macro.js` | 芯粒/封装/主板/笔记本 | 程序化贴图 + 圆角板 |

### 栅极怎样控制沟道

半透明是观察内部的画法。FinFET 的栅覆盖竖鳍的顶部和两侧。带斜面的源漏外延在栅区两端，受控沟道沿鳍穿过栅下。RibbonFET 的四条硅带各自隔着栅介质与同一个金属栅相邻。导通时，亮点沿硅沟道经过栅内区域，表示源极和漏极之间的导电路径。各代模型在同一个观察位置下变形，便于比较结构。

### 从电网跟到器件

背面供电与回流各用独立的金属网，跨层时通过同一网络的通孔相连。局部特写展示已有的 nano-TSV 从背面金属接到本地源漏触点；正面输入经自己的信号线到达栅极。通孔从正面预埋，键合翻面、减薄以后才露出末端并接上背面金属。

## 材质

`scene/materials.js` 提供 8 种：`silicon` `channel` `oxide` `metal` `emissive` `gateGlass` `rim` `energyFlow`。

- `rim` 是一圈 fresnel 外壳，负责 Intel 渲染里那种「金属被灯打亮」的棱线；
- `energyFlow` 是沿轴向流动的能量带，用世界坐标做相位，所以物体怎么动光带都不会跳。

环境光不是 HDR 文件，而是运行时用 canvas 画的一张等距柱状图再 PMREM 预滤——
里面刻意放了三条冷白灯带和一条暖色反射带，金属的高光就来自这里。

## 性能

- 光栅化 + 后期（ACES + UnrealBloom），没有阴影贴图（PPT 要求「去掉所有影子」）；
- 初版 V3 在 1600×1000 的 Intel Arc 设备上记录过 120 FPS。修订版新增了器件和布线几何，此数字仅供查阅原测试记录。
- 窄屏自动把相机后撤，保证主体不被裁掉；
- 右上角提供 高 / 中 / 低 三档：低档关掉 bloom、像素比降到 1.0。

## 自检工具

`tools/shoot.mjs` 用 CDP 直接驱动 Chrome：

```bash
node tools/shoot.mjs --url http://127.0.0.1:8123 --out shots/x.png --t 0.52,0.60
```

`t` 可以是任意进度，所以每次改完都能在同一批帧上做前后对比，而不是靠肉眼滚动。
所有验收截图都在 `shots/`。

## 可访问性 / 细节

- `prefers-reduced-motion` 时不跑文字位移；
- 文字用真实 `<h1>/<h2>/<p>`，有层级；
- 时间环、比例尺是 `aria-hidden` 的纯装饰；
- 键盘 `↑↓ PageUp PageDown Home End` 全部可用，答辩现场可以不用滚轮。
