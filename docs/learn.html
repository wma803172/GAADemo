FABRICATION

这只开关是怎么造出来的？

先认三个名字。电流进出的两端叫源极（S）和漏极（D），中间的路叫沟道，决定这条路好不好走的是栅极（G）。想象要在同一处架四座很薄的桥。车间的办法，是先把桥和临时垫层一起长出来，等两端固定后，再把中间的垫层去掉。图里蓝色是最后留下的硅。

材料准备

把硅和临时垫层交替长出来

先有一整片硅晶圆，可以想成一张很平的底板。在上面一层硅、一层硅锗地生长薄膜。硅将来让电流通过。硅锗在这里有个用处：两种材料对同一道去除工序的反应不同，以后可以优先拿掉硅锗。

找一找相邻蓝层中间的夹层。未来包到硅带下方的栅，就需要这部分空间。

定出器件轮廓

把叠层刻成窄条，先固定两头

用光刻和刻蚀留下细长的叠层，再用临时栅给中间的“开关位置”占位。在两端形成源极和漏极，让各层硅接到同一对端子。中间两侧的小绝缘隔墙把未来的栅与源、漏隔开。

沿着窄条看，两端像两座桥墩。下一步掏去中间垫层时，硅带仍有支撑。

释放沟道

拿走中间的垫层，留下四条硅桥

移走占位的临时栅，在这段开口内优先去掉硅锗。留下的薄硅带中段悬空，两端仍连在源、漏上。做这一步最难的是既要清干净缝隙，又要尽量少伤到硅带表面。

现在任挑一层，从源到漏都能走通。四条路共用起点和终点，这就是“并联”。

形成真正的栅

给每条带包绝缘层，再把空隙填上栅金属

先在所有暴露的硅表面形成极薄的栅介质，连硅带底面也覆盖。接着沉积栅材料，带间和外围的金属连成一个可接线的电极。正面送来一个栅压，就能从上下左右同时影响四条沟道。

换个方向看：站在源极这一端，朝漏极看四层桥面的断面。蓝心是硅，贴着蓝心的细圈是绝缘层，更外面才是栅金属。

连接器件

在正面给栅极和器件端子接线

晶体管已经做好，还得让它与别的开关讲话。正面细金属线把上一道逻辑门的输出送到这一道的栅极，另一个接点把输出送往下一级。需要接电源的端子则留出本地接点，和器件旁的供电通孔衔接。

把“通知开关开还是关”的线和“真正提供电能”的线分开追，它们接到不同的地方。

准备背面

先托住正面，再从背面磨薄

正面的细线路经不起直接拿捏。先给正面贴一片支撑晶圆，整片翻转，再从原来硅底板的背面逐步减薄，直到能接近预留通孔的一端。原先做好晶体管的那一面，翻过来后仍叫“正面”。

先找到支撑片，再找原来那块硅底板。被磨薄的是原来的底板，已完成的开关留在支撑片一侧。

建立 PowerVia 供电路径

在背面铺电网，用短通孔接回器件旁边

在减薄后的背面制作供电金属。电从封装接入，沿背面金属轨分配，再经很小的竖直通孔和本地接点抵达要供电的端子。VDD 是电源，VSS 是回流端，各有自己的线路。正面因此能腾出更多地方走信号。

沿一根竖线走到底。它在晶体管旁接到本地供电点。控制四条硅带的信号仍走正面。

SIGNAL & POWER

做完以后，它怎么把 0 变成 1？

把两只互补的开关合起来，就能做一个“反相器”。两只开关的栅都听同一个输入。上面一只通向电源，下面一只通向地，中间合起来的接点就是输出。点一下输入，看输出会接向哪边。

输入信号
VDD 电源 → 上方 p 型开关 导通VSS 地线 → 下方 n 型开关 关断
输出1

输入为 0 时，上方开关给输出端的小电容充电，把电压拉高，所以读到 1。

单看下方 n 型管：在源漏间有电压差时，把栅相对源的电压抬高，电子更容易从源端经过硅带到达漏端。金属栅和硅带之间隔着绝缘层，栅靠电场指挥。真实开关的电流会渐变，关断仍有微小漏电。去模型里开关四条沟道 →

把栅压调低，四条硅带会发生什么？

这只 n 型管的四条通道一起变得难以导电。四条路共用同一个栅端，所以一起响应。关断仍会有少量漏电。

相邻硅带之间为什么要先掏空，再填东西？

要让栅从每一条硅带的底面也能控制它。空隙给栅介质和栅金属留出位置，而介质保证硅和栅金属电气隔开。

背面已经有电了，为什么正面还需要走线？

背面把电源和回流送到单元。正面仍要传“哪个开关该开”的信号，以及把计算结果送往下一道逻辑门。

对照 Gemini 原演示

为什么把“平行栅极”改成“共用栅极、并联沟道”？

原稿第 668–699 行用透明方块穿过四条带。这里在第 4 步切开栅，逐条画出绝缘层和连通的金属。每条带都有四面受控，四条带在同一对源漏之间并联。

为什么分开画两根电源轨？

原稿第 626–662 行让两根柱子分别落在同一只管的两端。用它讲反相器会让人误以为开关一开就把电源接到地。这里用两只互补器件解释 VDD、VSS 和输出的连接。

原稿的 0.28 V、160 / 180 nm 和 8–10% 各有什么问题？

0.28 V 是原动画写死的切换点，第 782–815 行把低于它的光点全藏了。不同阈值器件有不同特性。第 909–913 行把 160 / 180 nm 写到带宽滑杆，这两个数在 Intel 的表 1 中指标准单元高度。第 353–360 行的 8–10% 对应布线收敛改善，用它描述晶体管密度会读错指标。Intel 技术简报与表 1
