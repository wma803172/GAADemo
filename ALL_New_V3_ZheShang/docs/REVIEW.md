## 二、旧版本里被骂过的 bug → 新版本怎么规避

| 旧版问题 | 根因 | 新方案 |
|---|---|---|
| 时间轴和画面对不上 | 两套独立的动画时间 | 只有一个 `p`，时间环和画面同源 |
| 单 fin 模型凭空消失 | 可见性被多个 flag 竞争改写 | 每个模型只有一个 `fade(v)`，`v` 只由 `p` 算 |
| 中途突然冒出第三个界面 | 章节窗口重叠 | 用 `win()` 定义严格不重叠的梯形窗口 |
| 菱形 fin 做不出来 | 用 box 硬拼 | 自写 `diamondLensGeometry`：菱形截面沿 Z 拉伸 |
| 转到侧面就变成 ribbon | 模型朝向写死 | 参数化模型 + 相机绕 Y 转，几何本身不动 |
| 模型外面被金属色盖住 | 栅极不透明 | `gateGlass` + `depthWrite:false` + 明确 renderOrder |
| 影子逻辑错误 | 实时阴影 | 全景不投阴影（PPT 明确要求去掉） |
| 电子太大、没有拖尾 | 普通 sprite | 自定义 shader 的 soft-dot 点，尺寸随距离衰减 |
| 文字卡到下面 / 错位 | 文案和 canvas 各算一套时间 | 文案由同一个 `p` 的章节 `u` 驱动 |
| 改一段动画就全垮 | 300 行都挂在同一串 p 上 | 每章一个函数、每个模型一个 `apply(state)` |

## 三、我自己发现并改掉的问题

截图验收时发现的（都记在 `shots/` 里）：

1. **`oxide` 材质成了镜子**：整块衬底被环境光吹成一片白，bloom 之后像个发光板。
   → 降低 metalness / clearcoat，把环境贴图整体压到 0.62。
2. **半透明材质被 `fade()` 改回不透明**：BEOL 玻璃柱变成一块不透明的蓝方块。
   → `makeFade` 第一次调用时记住 `origTransparent`，并新增 `baseOpacity`。
3. **左侧时间环从来没显示**：`Rail.render()` 忘了给宿主加 `is-on` 类。
   → 补上开关，并在 CSS 里加了一条竖向基线。
4. **最后一帧看不到 logo**：`u < 0.992` 把最后一章的 `u = 1` 排除掉了。
   → 最后一章单独放行。
5. **转场时相机穿模**：从 PowerVia 飞向宏观尺度的直线穿过了整摞互连。
   → 让互连先缩成一个小点再淡出（`zoomOut`），新镜头从画面外落进来。
6. **竖屏一片混乱**：正面视角被裁掉一半。
   → 按 `aspect` 自动后撤相机，并给底部文案加暗角。
7. **3nm 的菱形方向做错了**（用户两次指出，第二轮才改对）：
   - 第一版：一整条菱形棱柱横贯所有鳍片 → 侧面看是"箭头楔子"。
   - 第二版：改成逐鳍的**竖直**菱形 → 方向还是不对：菱形和 Gate 的轴向平行了。
   - 第三版：逐鳍、长轴沿鳍片，但仍是**扁片**，而且高比宽大一截 → 看着还是"立着"的。
   - 第四版：改成实心八面体 → 有体积了，但形状不对。
   - **最终：是"菱形柱体"**——菱形是**鳍片的横截面**（X-Y 平面），沿**鳍片方向（Z）**
     拉出一段柱体。所以侧视图里看到的是菱形正面 + 一侧的斜面（有厚度）。
     参考 PPT 第 10 页那张侧视图就是这个结构。
   → `diamondLensGeometry(0.92, 1.08, 1.30)`（不旋转）：X 0.92、Y 1.08、Z 沿鳍片 1.30。
     每鳍一根、每端一根，柱体内端插进栅极下面；机位同时改成"沿鳍片方向看的侧视图"、
     稍微偏一点 3/4，才能同时看到菱形正面和柱体的侧面。

8. **3nm 的收尾（用户第四轮反馈）**：
   - **菱形不缩放**：删掉了逐颗 `scale` 的生长动画，出现即最终尺寸。
   - **鳍片不能高过菱形**：菱形下移骑到鳍片顶端（`dy = STI_TOP + finH - 0.04`），
     鳍片顶被菱形盖住，读作"鳍片的顶就是菱形"、同一个零件。
   - **电流在接触面上**：新增 `diamondTube()`——一个**只有四个侧面、没有端盖**的菱形套筒，
     贴在菱形与栅极接触的那一段（从菱形内端往栅极里铺 0.78），
     用 `energyFlow` 材质跑流动光带。用开口套筒而不是实心副本，
     才不会把整颗菱形糊成白色。

## 四、事实核查

全站 30+ 个数字全部有出处，见 `docs/research.md`。几个**刻意没写**的：

- 18A 的 ribbon 宽度（Intel 只给 W1–W3P 代号，没给 nm）→ 文案写「W2、W3 两种」，不写数值；
- 18A 良率、nano-TSV 直径、背面套刻精度 → 一律不写；
- 「18% / 38%」在正文里没有加限定条件，但页脚与 `research.md` 记录了它对应 **0.75 V 等功耗点**，
  1.1 V 下是 25% / 36%。如果答辩被追问，按后者答。

## 五、已知取舍

- 宏观尺度（芯片 → 笔记本）是**非等比例**的：用缩放 + 淡入淡出模拟连续拉远，页面上有「非等比例」提示；
- 3nm 的菱形外延做了几何简化，只保留「菱形剖面 + 合并」这两个识别特征；
- 竖屏时隐藏了部分次要段落，保证一屏能读完。
