# Intel 18A · 芯片的另一面

沿着一个晶体管向下滚动，观察 RibbonFET 的四条硅纳米带怎样共用一个环绕栅，再跟着晶圆翻面，沿 PowerVia 的背面电网、通孔和本地接点追到器件。

下载并解压仓库后，双击 [docs/index.html](docs/index.html) 即可离线观看。在「四条路，上下叠放」这段，点「关上开关」再点「打开开关」，看四层沟道如何同时响应。要直接看背面电网，点网页顶部的「背面供电」，再向下滑动查看侧接通孔的特写。

结构采用示意比例。金色和蓝色分别表示供电和回流支路，青色表示正面栅极信号。

继续滑到晶圆画面下方，可以对比 FinFET 与 RibbonFET 的栅极截面、比较两种硅带宽度，以及切换一个反相器的输入。性能表列出标准 Arm 核心子电路上两个工作点的测量结果。
